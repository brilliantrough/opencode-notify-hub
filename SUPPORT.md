# Support

## Questions and setup help

Read the [documentation index](docs/README.md) and the relevant troubleshooting
section first. For reproducible setup questions, use GitHub Discussions when
enabled; otherwise open an issue using the Bug report template.

Include:

- component and version or commit;
- operating system and architecture;
- OpenCode, Node.js/pnpm, Flutter/Dart, Docker, or PostgreSQL versions as
  relevant;
- sanitized logs and exact reproduction steps;
- expected and actual behavior.

Never post credentials, `.env` files, authorization headers, HMAC signatures,
Firebase JSON, signing material, email verification/reset codes, or user
conversation content.

## Bugs and feature requests

Use the repository issue templates. Security vulnerabilities follow the private
process in [SECURITY.md](SECURITY.md), not the public tracker.

## Project status

The project is pre-release and maintained on a best-effort basis. There is no
commercial support SLA.
