# Domain Docs

This repository uses a single domain context.

## Before Exploring

Read the root `CONTEXT.md` and the relevant decisions under `docs/adr/`. Proceed silently if a referenced document does not yet exist.

## Vocabulary

Use canonical terms from `CONTEXT.md` in issues, PRDs, tests, and implementation. Do not substitute a term listed under `_Avoid_`. Resolve a genuine terminology gap through domain modeling before adding it to the glossary.

## Decisions

Surface any conflict with an existing ADR rather than silently overriding it. Add an ADR only for a consequential, difficult-to-reverse trade-off that would otherwise be surprising to future maintainers.
